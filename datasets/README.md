# datasets

Seed data for practice exercises: Employees, Departments, Customers, Orders, Products, Sales.

- `seed.sql` — schema + data for SQL Practice (Phase 1).
- `csv/*.csv` — the same six tables exported to CSV for the Data Analytics track (Phase 3). Generated from `seed.sql` (see `scripts` in project history) so the two tracks never drift apart.
- `csv/employees_messy.csv` — a deliberately dirty version of the employees table (missing values, inconsistent casing, stray whitespace, a duplicate row) used specifically by the Data Cleaning / Missing Values exercises.
